# 从教师分布到历史对手池 PPO

## 1. 教师数据：搜索得到监督目标

C 教师以 TRGoChessC 的 16 类棋型和 G11 权重给局面评分，使用带候选剪枝的 Alpha-Beta 搜索。每个局面串行搜索，OpenMP 并行不同棋局。

对局面 s 的根候选动作评分 q(s,a)，构造软标签：

```text
p_T(a|s) = exp((q(s,a) - max_b q(s,b)) / T)
           / sum_b exp((q(s,b) - max_c q(s,c)) / T)
```

T=100 使用原始棋型分数单位，不是胜率。所有根候选必须完成同一深度后才采用该轮评分；节点预算中途耗尽时回到上一完整深度，第一轮也无法完成则使用静态评分，记录深度 0。候选外概率为零，这是搜索教师的偏好，并非所有合法动作的完备评价。

轨迹通常执行标签最大概率动作，前两手使用中心区域随机开局，并以 0.1 的概率探索其他合法动作。保存的软标签仍来自教师。价值标签来自这条实际轨迹的终局胜负，以当前行棋方为视角，取 -1、0、1。

数据分片保存局面、软标签、终局结果、棋局 ID 和完成搜索深度。棋局 ID 对 `validation_every=10` 取模为 0 的整局留作验证，防止同一棋局的相邻局面泄漏。只读取软标签格式 2。

## 2. 蒸馏：同时训练策略和价值

输入是 `board * current_player`，己方为 +1、对方为 -1、空位为 0。网络采用 5×5 卷积、残差块、GroupNorm 和 SiLU；策略头输出每个落点的 logits，价值头全盘池化后输出 [-1,1] 的标量。

占用位置被屏蔽，策略损失使用软标签交叉熵：

```text
L_policy = -sum_a p_T(a|s) log pi_theta(a|s)
L_value  = (V_theta(s) - outcome)^2
L_distill = L_policy + 0.25 L_value
```

每批随机旋转、镜像棋盘，标签概率图同步变换。验证 KL = 交叉熵 - 教师标签熵；相比单纯交叉熵更容易看出学生与教师分布的差距。保存验证交叉熵最低的模型进入下一阶段。

## 3. 历史池 PPO：从模仿走向对弈

初始蒸馏模型先以 update 0 入池。每次更新后按间隔 10 加入新快照，FIFO 保留最近 64 份。每对棋局以 0.85 的概率均匀选择历史快照，其余对抗本批当前模型。每对使用相同随机开局、相同对手，学习者交换先后手。

一整批棋局完成前所有策略冻结。每盘只记录学习者一方的动作、旧 log probability 和价值，历史对手动作不加入 PPO。

设一盘总手数为 L（含随机开局），学习者视角胜负 z 为 +1/0/-1，终局奖励和第 t 手回报为：

```text
R = z * (1 - 0.4 * min(L / 100, 1))
G_t = 0.99^(L - 1 - t) * R
A_t = G_t - V_old(s_t)
```

其中 t 从 0 开始，按双方每一手计数。对手落子也占用折扣时间。赢得快奖励更高、输得慢惩罚较小，始终胜 > 和 > 负。局长超过 100 后塑形项封顶。

这里使用**完整棋局的 Monte Carlo 回报减去旧价值估计**，没有 GAE，也没有 MCTS。优势在整批学习者样本上标准化，再进入 PPO：

```text
r_t(theta) = exp(log pi_theta(a_t|s_t) - log pi_old(a_t|s_t))
L_PPO = -mean(min(r_t A_t, clip(r_t, 0.8, 1.2) A_t))
L_total = L_PPO + 0.5 mean((V_theta - G_t)^2)
          - 0.01 mean(entropy(pi_theta)) + 0.1 L_BC
```

L_BC 是同一教师数据上的软标签交叉熵，用于约束偏离示范策略的程度，不更新教师。每批最多遍历 4 次，若某 minibatch 的近似 KL 超过 0.03，则在执行该批梯度前终止本轮 PPO。

`mean_reward`、训练胜率和黑白得分率都取自更新前收集的棋局。对手池会变化，因此这些曲线用于训练诊断；固定 C 教师评估和实际对弈用于比较棋力。
